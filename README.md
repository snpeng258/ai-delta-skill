# ai-delta

生成变便宜了，验证没有。所以稀缺资源只有一个：**我的验证带宽**。

这个库是一份 skill：agent 读根目录 [SKILL.md](SKILL.md)。规矩：**我只管说话，记录是副产品。** 不填表，不整理，不设"整理时间"。

## 三份自动积累，一份手工提炼

| 文件 | 谁写 | 存什么 | 一条长什么样 |
|---|---|---|---|
| `vocab.md` | skill 自动 | 我问过的词 | 日期｜场景｜它指什么、不指什么｜session |
| `topology.md` | skill 自动 | 我问过的项目结构 | 层名 — 判据 |
| `cases.md` | skill 自动 | 值得翻回去的对话 | 日期｜标签｜现象｜缺什么｜session |
| `phrasing.md` | **只有我** | 我该怎么跟 AI 说 | 一句能粘出去的话 + 来自哪几条 case |

分界线：**一条记录如果需要看别的记录才能写，就不该自动写。** 前三份都是当场就知道的事实，第四份要跨多条案例比较——那是判断，是我唯一产生价值的地方。

`why.md` 是这些为什么长这样。读一次就够，不用维护。

## 触发：我说这句话，skill 就该动笔

| 我随口说的 | skill 做什么 |
|---|---|
| "什么是 X" "X 是什么意思" | `vocab.md` 加一行 |
| "这项目分几层" "这结构怎么回事" | `topology.md` 建一节或补一行 |
| "这个例子很好" "这次很对" | `cases.md` 加一行 `(+)` |
| "又碰到那个问题了" "它又修错层了" | `cases.md` 加一行 `(a/b/c/d)` |
| 同一类问题第五次进 `cases.md` | **随口提醒一句可以提炼说法，不许自己写 `phrasing.md`** |

写的时候不许反问我要补什么字段。信息不够就少写半行，宁可漏，不要打断我。

## 两条规矩

**一、写入只由说话触发，当场完成，一条不超过一行。**
做事和学习已经解耦，偷懒会被立刻奖励（更快交付），惩罚延迟几个月才到。所以任何依赖"我要更用心"或"等有空整理"的方案都会死。

**二、说不出差别就不记。**
判据：这件事换个人加同一个模型，结果会差多少？差不多就别记——那是中位解，收藏它只是攒景观。

## 第四层：卡片怎么用

**加载：标题永远读，正文按需读。**
调用时先只读 `vocab.md` 和 `topology.md` 里所有 `## ` 开头的行。标题自带一句话摘要，本身就是索引，用 `rg '^## '` 现场生成，永不过期。只对看起来相关的小节展开全文。

不做独立索引文件（派生物要同步，不同步就是静默失效），也不设阈值（状态切换是最容易不发生的事）。单一路径在 13 行和 3000 行时行为一致。

**关联：只提候选，不下结论。**
只在两种情况下提醒，最多两条，一行一条：

- 这次的用法和已记的某条不一致
- 这次的概念是已记概念的上位或下位

其余情况一律不提。**宁可漏掉一个关联，也不要每次塞给我三条像是有关的。** 我确认或修正之后，skill 才给对应词条补一层——那时写的是我刚说过的话，仍然是当场就知道的事实。

**提炼：只有我能做。**
`phrasing.md` 每一条都来自我读 `cases.md` 之后的判断。同一类问题第五次进 `cases.md` 时，skill 随口提醒一句就行，不严格计数，不许自己动笔。case 我自己会处理。

**开工时：** `phrasing.md` 全抄进问题陈述。`topology.md` 对应那节调出来当坐标系。

### 这一层还没定的

- 一条说法降级成机器约束之后，底部那行要不要留原始出处

## 唯一的进度条

`phrasing.md` 里的一行，从上面三节挪到底部「已经不用说了」。

从"我每次都得说"变成"机器帮我挡"。这个挪动次数是唯一不依赖自我感觉的进步指标。

为什么这样分带

  • • 一层一条横带，从上到下读就是四环
  • • 三份文本同处第三层，第四层才是用法
  • • 冲击到能力的对应写在盒子里，不拉斜线
  • • 能力到文本用右下角标签，不拉斜线

两种用法的转速差

  • • 词 / 拓：叠一层是当场就知道的事实，可以全自动
  • • 案 → 说法：要跨多条比较，只能我做
  • • 转速差就是该不该自动的判据

Obelisk 现状

  • • Cursor 对话已进库，标题带 [Cursor] 前缀
  • • 但 source 记成 claude，不是 cursor
  • • 换工作区会拆成多个 session id
  • • 中文检索用短词，长词组可能命中不到
先把它想成一个车间

第一层是故障报告，第二层是要练的工种。第三层是三本册子：词典和图纸钉在墙上，每次干活先扫一眼标题、确认后补一笔；事故本平时只往里夹纸条。第四层是这三本册子怎么用——前两本机器自己翻自己写，事故本只有你周末坐下来全部读完，读完写进带回家的笔记本。笔记本里有几条最后会变成车间规章，那才是机器每次开工都要执行的东西。
